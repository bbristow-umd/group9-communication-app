#Group 9 Communication Application
 Our team is developing one centralized collaboration platform. This allows users to have one location where users can interact one on one or in groups. Our application centralizes one location that allows for direct and group messaging, calendar information, scheduling and file sharing. This eliminates the need for users to have to pay for multiple different platforms allowing users to be more efficient.
